# FTC 32477 Origin · 新队员训练沙盒

本仓库是训练用沙盒（草稿纸 + 答题卡），与题目库
[`beginner-training`](https://github.com/ftc32477/beginner-training) 配套使用。

## 规则

- 本仓库内容**可随时清理或重置**，不要存放正式项目代码、资料或任何重要内容。
- 队员拥有写入权限；所有改动通过**分支 + Pull Request**提交，请勿直接推送 `main`（维护约定）。
- 严禁提交密钥、密码、Token、真实项目代码、内部资料与他人隐私；截图须先去敏。

## 目录

| 目录 | 用途 |
|------|------|
| `scratch/` | 自由草稿 |
| `github/` | GitHub 操作练习答题区（对应题目库 gh-xx） |
| `onshape/<用户名>/` | Onshape 练习成果：截图 / DXF / STEP + 说明 |
| `programming/<用户名>/` | 程序练习代码 |

## 提交方式

1. 从 `main` 新建分支，如 `gh-03/your-username`。
2. 在对应目录完成练习并提交，提交信息注明练习编号。
3. 推送分支并创建 Pull Request，等待负责人审查；意见在 PR 中讨论。
4. 通过后由维护者合并。
